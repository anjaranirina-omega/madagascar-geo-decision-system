# Script de démonstration — RISKCLIM-MG

## Durée cible

```txt
10 à 12 minutes
```

## Ordre recommandé

1. Login
2. Dashboard
3. Carte
4. Analyse multicritère
5. Données / pipeline
6. Alertes / signaux opérationnels
7. Rapports
8. DWH / SOLAP
9. Conclusion

## Message clé

RISKCLIM-MG transforme des données réelles en informations décisionnelles spatiales :

```txt
sources → ETL → rasters → indicateurs → DWH/SOLAP → carte/dashboard/rapports/alertes
```

## Points à montrer

### Login

- connexion ;
- rôles.

### Dashboard

- KPI ;
- risques par région ;
- sources ;
- ETL.

### Carte

- risques global, inondation, sécheresse, glissement, cyclone ;
- recherche ;
- limites administratives ;
- risque local.

### Analyse

- poids globaux ;
- poids spécifiques ;
- aléa / risque.

### Données

- pipeline asynchrone ;
- sources connectées ;
- jobs ETL.

### Alertes

- alertes validées ;
- signaux opérationnels ;
- météo temps réel.

### Rapports

- PDF national ;
- historique ;
- comparaison.

## Conclusion

RISKCLIM-MG est une plateforme complète d'aide à la décision climatique pour Madagascar, basée sur des données réelles, des modèles raster et des outils décisionnels.
